How the flow works

The app is structured as a step-by-step workflow for exploring a DEM, defining release areas, adjusting the simulation settings, and running the avalanche model in the browser.

  1. Shortcut: pick one of the bundled AvaFrame examples and run it directly.
  2. Select DEM: upload a .gpx, .tif/.tiff, .asc, or a Zarr store directory. GPX tracks download matching elevation tiles in Austria, while Zarr stores let you choose a site from the uploaded store.
  3. Select release areas: either calculate them from the terrain or upload a matching release area raster. For Zarr stores, pick a scenario from the selected site.
  4. Simulation settings: tune the model, friction, particle, and solver parameters.
  5. Run simulation: execute the model and inspect the generated plots.
  6. Save results: download the simulation results as Zarr store. Only works for Chromium based browsers.

Zarr stores are expected to follow the site/scenario layout produced by the data processor, and the browser decodes chunks directly in WASM so the workflow stays fully in the app.
